# Таксометр (Hyundai Sonata 2017 + OBD-II Bluetooth)

Android-приложение: подключается по Bluetooth к ELM327-адаптеру в диагностическом
разъёме автомобиля, считает фактически пройденное расстояние с момента нажатия
**СТАРТ**, ведёт время простоя и рассчитывает стоимость поездки по выбранному
тарифному профилю.

- `compileSdk` / `targetSdk` 35, `minSdk` 26 — работает на Android 15 / One UI 8.5
- Kotlin 2.0, Jetpack Compose (Material 3), без внешних OBD-библиотек

## Как считается пробег — важно

**Штатный одометр Hyundai Sonata 2017 через стандартные OBD-II PID прочитать
нельзя.** Его значение живёт в приборной панели и по диагностическому разъёму в
открытом виде не отдаётся; стандарт OBD-II (SAE J1979) такого параметра просто
не содержит.

Поэтому приложение делает то же, что и все OBD-таксометры:

1. опрашивает PID `010D` (скорость автомобиля по данным ЭБУ) с частотой 10–20 Гц;
2. интегрирует скорость по реальным метткам времени методом трапеций:
   `Δs = (v₁ + v₂) / 2 · Δt`;
3. умножает результат на коэффициент калибровки.

Расхождение с одометром обычно 1–3 %. Чтобы его убрать: проехать по одометру
ровно 10 км, посмотреть показания приложения и ввести коэффициент
`одометр / приложение` в **Тарифы → Калибровка пробега**.

Защита от артефактов связи: если между выборками скорости прошло больше 3 секунд
(реконнект, зависший адаптер), интервал не учитывается — иначе одна дырка в связи
дала бы километры из воздуха.

Дополнительно на экране адаптера показывается PID `0131` — пробег с момента
сброса ошибок, с шагом 1 км. Это грубая сверка, для таксометра он слишком
дискретный.

## Экраны и кнопки

**Главное меню** — стартовый экран
- **Начать поездку** (крупная зелёная кнопка) → выбор тарифа, после выбора
  (или по «назад») — таксометр. Пока поездка идёт, кнопка желтеет и показывает
  её сводку: состояние, сумму, километры и длительность; нажатие возвращает
  к таксометру.
- **Статистика** — переключатель периодов и подробная сводка, см. ниже.
- **Настройки** — тарифные профили, доплаты за услуги, OBD-адаптер.

Завершённые поездки складываются в общую историю (последние 500) и дальше
живут только в статистике. Смен в приложении нет.

**Таксометр**
- название выбранного тарифа
- крупная текущая сумма и крупный счётчик пройденных километров
- таймеры «в пути» и «простой»
- галочки дополнительных услуг
- **СТАРТ** → **ПАУЗА** / **СТОП**
- в шапке: гамбургер (в меню) и ценник (выбор тарифа)
- полоса-предупреждение при потере связи с авто

**СТАРТ** обнуляет счётчики и запускает интегрирование.
**ПАУЗА** останавливает подсчёт расстояния и начинает подсчёт простоя.
**СТОП** фиксирует итог и показывает попап с результатом поездки: сумма,
расстояние, простой, время начала и конца, длительность. Там же выбирается
способ оплаты — **Наличные** или **Карта**, одно из двух. Без выбора кнопка
**Завершить поездку** ругается и ничего не делает; попап нельзя закрыть мимо,
иначе поездка не попала бы в статистику. После завершения счётчик обнуляется,
а приложение возвращается к выбору тарифа под следующего клиента.

Пока поездка идёт, работает foreground-сервис: опрос адаптера не прерывается,
когда экран погас или приложение свёрнуто. В уведомлении видно километры, сумму
и время простоя.

**Выбор тарифа** (ценник в шапке таксометра) — только список профилей.
Касание выбирает тариф и возвращает на таксометр.

**Тарифные профили** (Настройки → Тарифные профили) — тот же список плюс
добавление, редактирование и удаление.

Сменить тариф можно только когда поездки нет: во время неё и на завершённой
карточки не нажимаются, иначе пересчиталась бы уже показанная сумма.

**Адаптер** — список спаренных Bluetooth-устройств, подключение и диагностика.

Выбранный адаптер запоминается: при следующем запуске приложение подключается
к нему само. Если связь оборвалась, оно повторяет попытки с нарастающей паузой
(3, 5, 10, 20, дальше каждые 30 секунд) — пока не подключится или пока вы не
нажмёте «Отключить». Кнопка отключения выключает и автоповтор.

## Статистика

Переключатель периодов: **День** (с начала суток), **Неделя** (последние
7 дней), **Месяц** (последние 30 дней), **Всё** (вся сохранённая история).

Что считается за период:

| Блок | Содержимое |
|---|---|
| Итого | выручка крупно, кольцо долей оплаты с процентами и суммами |
| Плитки | поездок, километров |
| Додатково | время в поездках, самая дорогая поездка |
| Додатково (не День) | дней с поездками, в среднем за день, поездок в день |
| График | выручка по дням; за День не строится; сегодняшний столбик зелёный |
| По тарифам | поездки и выручка по каждому профилю |
| Поездки | кнопка с количеством; раскрывает список, касание поездки — её полную карточку |

У каждой поездки в списке справа корзинка: удаление спрашивает подтверждение
с датой и суммой, после него статистика пересчитывается.

Раскрытая поездка показывает начало и конец, время в пути и простоя,
длительность, расстояние, тариф, способ оплаты, услуги с суммой доплат
и фактическую цену за километр.

Расчёты живут в [`data/Stats.kt`](app/src/main/java/com/taxi/meter/data/Stats.kt),
графики нарисованы средствами Compose без внешних библиотек.

## Тарифный профиль

| Поле | Смысл |
|---|---|
| Название профиля | как он отображается в списке |
| Стоимость 1 км, грн | цена за каждый начатый километр сверх минимального расстояния |
| Стоимость простоя, грн/мин | цена за каждую начатую минуту на паузе |
| Минимальная цена за поездку, грн | нижний порог стоимости |
| Мин. расстояние для мин. цены, км | в его пределах берётся только минимальная цена |

## Дополнительные услуги

Дети, животные и багаж в салоне — галочки на главном экране. Каждая включённая
услуга прибавляет свою цену к минимальной стоимости поездки. Набор услуг
сбрасывается после завершения поездки.

Цены задаются **один раз для всех тарифов**: Тарифы → Доплаты за услуги.
Хранятся в `AppSettings.servicePrices`, а не в профиле.

Тарификация идёт целыми единицами с начала каждой: как только машина заехала
в очередной платный километр, он оплачивается полностью; как только пошла
очередная минута простоя — она оплачивается полностью.

```
платныеКм    = ceil(км - минРасстояние)     ограничено снизу нулём
платныеМин   = ceil(секундыПростоя / 60)
доплаты      = сумма цен включённых услуг
минЦена+     = минЦена + доплаты

если минРасстояние > 0:
    за расстояние = минЦена+ + платныеКм * ценаЗаКм
если минРасстояние = 0:
    за расстояние = max(минЦена+, платныеКм * ценаЗаКм)

итого = за расстояние + платныеМин * ценаПростоя
```

Тариф «60 грн до 2 км, дальше 15 грн/км»: 2.00 км → 60 грн, 2.01 км → 75 грн,
3.00 км → 75 грн, 3.01 км → 90 грн. Простой 0 с → 0 грн, 1 с → одна минута,
61 с → две минуты.

Логика проверена юнит-тестами: `app/src/test/java/com/taxi/meter/FareTest.kt`.

## Подключение к машине — пошагово

### Шаг 1. Какой адаптер покупать

Нужен **ELM327 с Bluetooth Classic (SPP)**. Это принципиально: приложение
работает через RFCOMM, то есть классический последовательный профиль.

Что **не подойдёт**:

- адаптеры **BLE 4.0 «для iPhone»** — у них нет SPP, Android их увидит, но
  соединение не откроется;
- **Wi-Fi адаптеры** — другой транспорт целиком;
- совсем дешёвые клоны с наклейкой «V2.1»: чип там часто урезанный, ответы
  приходят медленно или обрываются.

Что берут и что работает:

| Адаптер | Замечание |
|---|---|
| OBDLink LX | самый надёжный, быстрый опрос, уходит в сон |
| Vgate iCar Pro **Bluetooth 3.0** | не перепутайте с версией BLE 4.0 |
| Konnwei KW902 | дешёвый рабочий вариант |
| Любой ELM327 v1.5 на чипе PIC18F25K80 | смотрите описание продавца |

### Шаг 2. Найти разъём в Sonata 2017

Разъём OBD-II — **под рулевой колонкой слева, над педалями**, рядом с рычагом
открывания капота. Трапециевидный, на 16 контактов, иногда прикрыт пластиковой
заглушкой без надписей — её нужно поддеть и снять.

Машина должна стоять на ручнике, зажигание выключено.

### Шаг 3. Вставить адаптер

Вставьте до упора, до лёгкого щелчка. Разъём запитан постоянно, поэтому
светодиод на адаптере загорится сразу, ещё до зажигания.

### Шаг 4. Включить зажигание

Поверните ключ в положение **ON** (вторая позиция, приборка загорелась). С кнопкой
Start-Stop — нажмите её **не нажимая тормоз** два раза.

Без зажигания ЭБУ обесточен: адаптер спарится, но на запросы придёт «ЭБУ
не отвечает». Заводить двигатель не обязательно, но с заведённым видно обороты
и напряжение — так проще убедиться, что всё работает.

### Шаг 5. Спарить адаптер с телефоном

Это делается **в системных настройках Android**, а не в приложении — приложение
показывает только уже спаренные устройства.

1. Настройки → Подключения → Bluetooth.
2. Найдите устройство с именем вроде `OBDII`, `OBD2`, `ELM327`, `V-LINK`,
   `Vgate`, `KONNWEI`.
3. Нажмите, введите PIN — **1234**, реже **0000**.
4. Дождитесь «Сопряжено».

Если телефон уже соединён с магнитолой Sonata — это не мешает. Магнитола и
адаптер независимы, работать будут одновременно.

### Шаг 6. Первый запуск приложения

1. При первом открытии дайте два разрешения: **«Ближайшие устройства»**
   (это Bluetooth) и **«Уведомления»** — без второго не будет видно поездку
   на заблокированном экране.
2. Главное меню → **Настройки** → **OBD-адаптер**.
3. В списке спаренных устройств нажмите свой адаптер.
4. Статус пройдёт «Подключение...» → **«Подключено»**, появится строка
   протокола — у Sonata 2017 это `ISO 15765-4 (CAN 11/500)`.

### Шаг 7. Убедиться, что данные идут

На том же экране адаптера, с заведённым двигателем:

- **Обороты** — около 700–800 на холостых, растут при нажатии газа;
- **Напряжение** — 13.8–14.4 В на заведённой, 12.4–12.7 В на выключенной;
- **Частота опроса** — 10–20 Гц; если меньше 5 Гц, адаптер медленный и пробег
  будет считаться грубее;
- **Скорость** — 0 на стоянке, меняется при движении.

Если всё это показывается — связь настроена.

### Шаг 8. Настроить тарифы

Настройки → **Тарифные профили**: цена за км, простой, минимальная цена
и расстояние, до которого она действует. Отдельно — **Доплаты за услуги**
(дети, животные, багаж), они общие для всех тарифов.

### Дальше — каждый день

Сели в машину, завели — приложение подключится к адаптеру **само**, выбирать
из списка больше не нужно. Адрес адаптера запомнен.

Дальше: **Начать поездку** → выбрать тариф → **СТАРТ** → **СТОП** → способ
оплаты → **Завершить поездку**.

### Если что-то не работает

| Что видите | Что делать |
|---|---|
| Адаптера нет в списке при поиске Bluetooth | Не запитан — проверьте, до конца ли вставлен, горит ли светодиод. Или это BLE-версия: она не подойдёт |
| Спарился, но в приложении «Не удалось подключиться» | Выньте и вставьте адаптер, в настройках Bluetooth «Забыть устройство» и спарьте заново |
| «ЭБУ не отвечает. Включите зажигание» | Зажигание в положении ON, приборка горит |
| Подключается и сразу отваливается | Слабый контакт в разъёме или дешёвый клон. Приложение будет переподключаться само, но лучше сменить адаптер |
| Подключено, но скорость всегда 0 | Так и должно быть на стоянке. Проверяйте в движении |
| Пробег расходится с одометром | Ожидаемо 1–3 %: приложение считает по скорости с ЭБУ, а не по одометру |

### Важно про стоянку

Дешёвые адаптеры **не уходят в сон** и тянут ток из разъёма постоянно. Если
машина стоит несколько дней, вынимайте адаптер — иначе можно посадить
аккумулятор. OBDLink и Vgate iCar Pro засыпают сами, им это не грозит.

## Сборка

На этой машине нет JDK, Android SDK и Gradle, поэтому APK не собран — только
исходники. Wrapper-jar в репозиторий не положен (бинарник), см. вариант 1.

### Вариант 1 — Android Studio (проще всего)

1. Android Studio Ladybug или новее, JDK 17.
2. `File → Open` → папка `Taxi`.
3. Studio сам предложит скачать Gradle 8.9 и создать wrapper; согласиться.
4. `Build → Build App Bundle(s) / APK(s) → Build APK(s)`.

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Если wrapper не создался: `Tasks → build setup → wrapper` в панели Gradle, либо
из терминала со установленным Gradle:

```bash
gradle wrapper --gradle-version 8.9
```

### Вариант 2 — GitHub Actions (APK без установки инструментов)

В репозитории лежит `.github/workflows/android.yml`. Загрузить папку в
GitHub-репозиторий, workflow соберёт debug-APK и положит его в артефакты сборки.

### Запуск тестов

```bash
./gradlew test
```

## Установка на телефон

Debug-APK подписан отладочным ключом — для личного пользования этого достаточно.
На Samsung с One UI: скопировать APK на телефон, открыть, разрешить установку из
неизвестных источников. При первом запуске выдать разрешения на Bluetooth
(«Ближайшие устройства») и уведомления.

## Известные ограничения

- Пробег считается от скорости с ЭБУ, а не с одометра — см. раздел о калибровке.
- Простой считается только по нажатию **ПАУЗА**. Автоматический простой при
  остановке в пробке не реализован.
- Незавершённая поездка не сохраняется на диск: если систему заставить убить
  процесс (например, вручную закрыть приложение), счётчики обнулятся.
- Незавершённая поездка не попадает в статистику: запись делается по кнопке
  «Завершить поездку» в итоговом попапе.
